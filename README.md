# 🎮 IELTS 消消乐 | IELTS Vocabulary Match Game

🌐 **A gamified vocabulary learning tool designed by an educator for IELTS learners.**

---

## 👨‍🏫 About the Creator | 关于作者

I am an English educator with extensive experience teaching IELTS and PTE students.  
我是一名英语教育工作者，长期从事 IELTS、PTE 及学术英语教学。

Through my teaching experience, I noticed that many students found vocabulary memorization repetitive and difficult to maintain.

在教学过程中，我发现很多学生觉得传统的单词记忆方式枯燥、重复，也很难长期坚持。

So I designed **IELTS 消消乐** — turning vocabulary review into a simple and enjoyable game. 🎯

因此，我设计了 **IELTS 消消乐**，希望把原本枯燥的词汇复习变成一个轻松、有趣的小游戏。 🎮

---

## 💡 Why I Built It | 设计初衷

📚 **Problem:** Students often know that vocabulary is important, but lack motivation to review it regularly.

🎮 **Idea:** What if vocabulary practice felt more like playing a game than studying?

✨ **Goal:** Make repeated vocabulary exposure more engaging, enjoyable, and sustainable.

> **Learning doesn't always have to feel like studying.**

---

## 🎯 What It Does | 功能

- 🧠 Practice IELTS vocabulary through a matching game
- 🎮 Turn repetitive review into a game
- 🔄 Encourage repeated exposure to vocabulary
- ⚡ Provide a quick and low-pressure way to review words
- 😊 Make English learning more enjoyable

---

## 🚀 How to Use | 使用方法

1. Open the game in your browser. 🌐
2. Start the game and find matching vocabulary items. 🔍
3. Match the correct pairs and continue playing. 🧩
4. Repeat regularly to reinforce vocabulary memory. 🔄

No installation required — just open and play! 🎉

---

## 🌱 Educational Philosophy | 教育理念

This project reflects my belief that **educational technology should begin with a real learning problem**.

这个项目体现了我的一个教育理念：

> **Technology should not replace teaching — it should help create better ways for students to learn.**

当我们发现学生“不想学”时，与其简单地要求他们更加努力，不如思考：

**我们能不能创造一个让他们更愿意学习的环境？** 💡
